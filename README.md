# Backstage for Mere Mortals

Plain-language guides to Backstage: the open-source internal
developer portal that answers "who owns this service, where are its
docs, and how do I make a new one correctly." Written for people who
run real systems — no CS degree required.

No jargon without an explanation. No "it's simple, just..." Every
concept starts with the *idea*, then the practice.

3. [Software Templates](software-templates.md) — scaffolding new
